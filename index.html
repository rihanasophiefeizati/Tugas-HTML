Tentang Coding Club

Coding Club SMKN 1 Subang dibentuk untuk mewadahi siswa yang ingin memperdalam kemampuan pemrograman di luar jam pelajaran sekolah. Kegiatan dijalankan secara rutin dengan bimbingan mentor dari kakak kelas dan guru pembina, sehingga siswa bisa belajar dengan suasana yang santai namun tetap terarah.

Manfaat mengikuti Coding Club antara lain menambah keterampilan teknis yang berguna untuk dunia kerja maupun kuliah, melatih kemampuan berpikir logis dalam memecahkan masalah, serta membuka kesempatan untuk mengikuti berbagai kompetisi IT tingkat sekolah maupun regional.

Kegiatan Coding Club

Belajar HTML

Anggota mempelajari struktur dasar halaman web menggunakan HTML, mulai dari heading, paragraf, list, hingga elemen semantic.

Membuat Website

Anggota berlatih membangun website sederhana secara langsung, menggabungkan HTML dan CSS untuk membuat tampilan yang rapi.

Project Showcase

Anggota mempresentasikan proyek yang telah dibuat di depan teman-teman dan mentor untuk mendapatkan masukan dan apresiasi.
